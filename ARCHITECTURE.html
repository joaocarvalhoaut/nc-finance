Mapa da aplicação

SaaS de cobrança automatizada por WhatsApp. As camadas fluem de cima para baixo: o cliente (React) chama as Edge Functions (Deno), que operam o banco (Postgres + RLS) e conversam com serviços externos. Clique numa Edge Function para acender as tabelas e integrações que ela usa.

Clique numa função para destacar suas dependências · clique de novo (ou no fundo) para limpar.

Camada 2 · Edge Functions — Deno (18)
